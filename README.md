# 🗄️ E-Commerce Database Design using MySQL

## 📌 Project Overview

This project demonstrates the design and implementation of an e-commerce database using MySQL. It includes table creation, relationships, constraints, data manipulation, and analytical SQL queries.

---

## 🎯 Objective

To design a relational database and perform SQL operations for managing products, customers, and orders.

- SQL
